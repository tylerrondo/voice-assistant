# ТЗ-VOICE-SC-PASS-002: Голосовой диалог пассажира с несколькими откликами сервиса и выбором предложения

## 1. Назначение и Контракт
Сценарий проверяет способность голосовой платформы вести интерактивный сравнительный диалог по нескольким доступным откликам сервиса:
- **Информационные запросы:** Вопросы типа `«Какой быстрее?»`, `«А какой дешевле?»`, `«А второй — это комфорт?»`, `«Далеко находится второй?»` разрешаются в соответствующие информационные интенты и предоставляют ответы без изменения состояния выбора и со строгим инвариантом `executionCount === 0`.
- **Естественное разрешение ссылок:** Реплика `«Тогда давайте второй»` детерминированно извлекает слот `selectedOfferId = 'OFFER-B'` без необходимости произносить ID или формальную команду.
- **Ambiguity Guard:** Запрос `«Машину подешевле»` при наличии нескольких подходящих вариантов возвращает `AMBIGUOUS_SLOT` с декларативным промптом уточнения, не допуская случайного угадывания.
- **Zero-Execution Invariant:** До получения окончательного `confirmation = 'CONFIRMED'` счётчик исполнений `executionCount === 0` и `dispatcherCalls === 0`.
- **Exactly-Once Action:** После подтверждения создается ровно одно логическое исполнение (`executionId`, `idempotencyKey`), содержащее исключительно выбранный `offerId` (`OFFER-B`).
